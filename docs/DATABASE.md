# مخطط قاعدة البيانات

ملف واحد: `data/app.db` (SQLite، وضع WAL، المفاتيح الأجنبية مفعّلة). تُطبَّق ملفات `src/migrations/*.sql` تلقائيًا بالترتيب عند التشغيل، ويُسجَّل كل ترحيل في الجدول `schema_migrations`. لإضافة تعديل مستقبلي: أنشئ ملفًا جديدًا مثل `003_xxx.sql` — لا تعدّل الملفات القديمة.

| الجدول | الغرض |
|---|---|
| `users` | الحسابات: اسم المستخدم، كلمة المرور المجزأة (scrypt)، الدور (`student` / `editor` / `admin`)، التفعيل، إلزام تغيير كلمة المرور، عداد المحاولات الخاطئة والقفل |
| `students` | الصف والشعبة والصورة الشخصية، و**الموافقات**: نشر الاسم، نشر الصورة، مرجع الموافقة، من سجّلها ومتى. لا يُخزَّن هاتف أو بريد أو عنوان |
| `sessions` | الجلسات (يُخزَّن تجزيء الرمز فقط) ورمز CSRF وانتهاء الصلاحية |
| `categories` | التصنيفات: الاسم، الرابط، الوصف، الترتيب، الظهور |
| `articles` | المقال: معرّف عام ثابت `public_id`، الكاتب (مرتبط بالحساب)، العنوان والعنوان الفرعي والمقدمة، المتن ككتل JSON، صورة الغلاف ووصفها، الحالة، مميز/قلم واعد/أولوية الرئيسية، القراءات، والتواريخ: الإنشاء، آخر تعديل، الإرسال، الاعتماد، النشر، إلغاء النشر، الأرشفة |
| `media` | كل صورة: النوع (`cover` / `inline` / `profile` / `site` / `issue`)، المالك، المقال، الأبعاد، الحجم، مكان الملف. صلاحية العرض تُحسب عند كل طلب |
| `article_revisions` | نسخة كاملة من المقال عند كل إرسال (نص الطالب الأصلي) وعند كل تعديل تحريري مع سببه |
| `editorial_notes` | ملاحظات المحررين، مع تحديد ما يراه الطالب وما هو داخلي |
| `article_events` | سجل كل انتقال: الإجراء، من الحالة، إلى الحالة، المنفّذ، الملاحظة، الوقت |
| `issues` | أعداد الجريدة: الرقم، العنوان، الموضوع، الافتتاحية، صورة الغلاف، الحالة |
| `settings` | إعدادات الجريدة (JSON): الهوية، الجهة التعليمية، هيئة التحرير، الصور، صفحة المبادرة، الأغلفة، النشر |
| `writing_prompts` | أفكار الكتابة المقترحة للطلبة |
| `audit_log` | سجل العمليات الحساسة (الدخول، الحسابات، الموافقات، النشر، الحذف، الإعدادات) — عناوين IP مجزأة لا صريحة |

## صيغة متن المقال
لا يُخزَّن HTML. يُخزَّن المتن كقائمة كتل، مثل:
```json
[
  {"t": "p", "text": "فقرة فيها **عريض** و *مائل*"},
  {"t": "h2", "text": "عنوان داخلي"},
  {"t": "img", "m": "معرّف-الصورة", "cap": "وصف الصورة"},
  {"t": "ul", "items": ["عنصر", "عنصر"]},
  {"t": "quote", "text": "اقتباس"}
]
```
يُحوَّل إلى HTML عند العرض بعد هروب كل النصوص — فلا يمكن حقن أي كود في المقالات.
