# الصحفي الصغير

جريدة مدرسية إلكترونية لمدرسة طلحة بن عبيدالله للتعليم الأساسي بنين (5–12) — المديرية العامة للتعليم بمحافظة مسقط.

يكتب الطالب مقاله في **مكتبه الصحفي**، ويرفق صوره، ثم يرسله إلى **غرفة التحرير**. تراجع هيئة التحرير المقال، وقد تعيده بملاحظات، ثم تعتمده وتنشره في **الجريدة العامة**. لا يُنشر أي شيء تلقائيًا.

| الواجهة | العنوان | من يدخلها |
|---|---|---|
| الجريدة العامة | `/` | أي زائر، بلا تسجيل دخول |
| مكتب الطالب | `/desk` | الطالب بحسابه الخاص |
| غرفة التحرير | `/newsroom` | المحرر ومسؤول الجريدة |
| الغلاف الأمامي / الخلفي | `/cover` و `/cover/back` | الجميع (قابل للطباعة PDF) |

## 1. التشغيل على جهازك (ويندوز) — بلا أوامر

### المرة الأولى فقط: ثبّت Node.js
نزّل نسخة **LTS** من الموقع الرسمي **nodejs.org** وثبّتها بالضغط على «التالي» حتى النهاية.

### التشغيل: نقرة مزدوجة
1. افتح مجلد المشروع في مستكشف الملفات.
2. انقر نقرًا مزدوجًا على الملف **«تشغيل الجريدة.bat»**.
3. تُفتح نافذة سوداء صغيرة — **اتركها مفتوحة** ما دمت تستخدم الجريدة — ويُفتح المتصفح تلقائيًا.
4. **في أول مرة فقط** تظهر صفحة «مرحبًا بك»: اكتب اسمك واسم مستخدم بالإنجليزية وكلمة مرور، فيُنشأ حساب مسؤول الجريدة وتدخل مباشرة إلى غرفة التحرير. هذه الصفحة لا تعمل مرة أخرى بعد إنشاء الحساب.
5. في المرات التالية يُفتح المتصفح على الجريدة، وتدخل من «دخول الكتّاب» أو من **http://localhost:3000/login**.

لإيقاف الجريدة: أغلق النافذة السوداء.

> إن ظهرت رسالة «الجريدة تعمل بالفعل»: النافذة السوداء مفتوحة من قبل، افتح المتصفح على http://localhost:3000 مباشرة.

### من داخل Visual Studio Code (بديل)
1. **File ← Open Folder** واختر المجلد الذي فيه `server.js` (مجلد `AlSahafiAlSaghir` الداخلي).
2. **Terminal ← New Terminal** — تُفتح الطرفية في المجلد الصحيح تلقائيًا.
3. اكتب `npm start` ثم Enter.

> لا تحتاج `npm install` إطلاقًا. البيانات تُحفظ في المجلد `data` داخل المشروع، وتبقى بعد الإيقاف وإعادة التشغيل.
> (للاستضافات التي لا يوجد فيها متصفح، ما زال الأمر `node scripts/create-admin.js` متاحًا.)

## 2. أول ما تفعله بعد الدخول

1. **إعدادات الجريدة** (`غرفة التحرير ← إعدادات الجريدة`)
   - راجع أسماء الوزارة والمديرية والمدرسة وهيئة التحرير.
   - **ارفع الصور:** صورة المدرسة، صورة مدير المدرسة ورئيس التحرير، صورة المعلم المشرف العام. تظهر فورًا في الغلاف الأمامي.
   - شعار الوزارة وشعار المدرسة: ارفع **الملفات الرسمية الأصلية فقط**. لم يُضمَّن في التطبيق أي شعار رسمي.
2. **أضف الطلبة** (`الطلبة والموافقات`)
   - طالب واحد: الاسم والصف والشعبة ← «إنشاء الحساب».
   - مجموعة: سطر لكل طالب بالصيغة `الاسم، الصف، الشعبة` مثل:
     ```
     أحمد بن سالم البلوشي، 7، 2
     يوسف بن خالد الهنائي، 9، 1
     ```
   - تظهر **بطاقات دخول للطباعة** فيها اسم المستخدم وكلمة مرور مؤقتة. **تظهر مرة واحدة فقط** — اطبعها وسلّمها لكل طالب يدًا بيد.
   - عند أول دخول يُجبَر الطالب على اختيار كلمة مرور خاصة به.
3. **سجّل الموافقات** (صفحة كل طالب ← «موافقات النشر»)
   - دون موافقة مسجلة: يظهر توقيع المقال «بقلم طالب من الصف السابع» بلا اسم ولا صورة.
   - بعد تسجيل موافقة ولي الأمر: يظهر «بقلم الطالب: الاسم» وصورته الدائرية.
   - اكتب مرجع الموافقة (رقم النموذج وتاريخه) للتوثيق.
4. **أنشئ العدد الأول** (`الأعداد والغلاف`): العنوان، موضوع العدد، الافتتاحية، صورة الغلاف، ثم اجعله «صادر» و«العدد الحالي».
5. (اختياري) أضف **أفكارًا للكتابة** في «غرفة الأفكار» لتظهر للطلبة في مكاتبهم.
6. (اختياري) أضف **محررين** في «فريق التحرير»: المحرر يراجع وينشر، ولا يدير الطلبة أو الإعدادات.

## 3. دورة حياة المقال

```
مسودة ← مرسل للمراجعة ← قيد المراجعة ← معتمد ← منشور
              ↘ يحتاج إلى تعديل (يعود للطالب بملاحظات) ↗
              ↘ مرفوض (مع السبب)
منشور ← إلغاء النشر (يعود معتمدًا) أو أرشفة
```
- **الاعتماد منفصل عن النشر:** يمكن اعتماد المقال اليوم ونشره لاحقًا أو **جدولة** نشره.
- عند كل إرسال تُحفظ **نسخة كاملة** من نص الطالب. التعديل التحريري يتطلب كتابة سببه، ويُحفظ قبل التعديل وبعده.
- كل انتقال يُسجَّل مع وقته ومن نفّذه (يظهر للمحررين فقط).

## 4. التجهيز للاستضافة

اقرأ الدليل الكامل: **[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)**. الملخص:

- يحتاج التطبيق **خادمًا يشغّل Node.js 22.13+ باستمرار** و**قرصًا دائمًا** للبيانات والصور.
- **لا يصلح Vercel** لهذا التطبيق (يناسب ألعاب HTML الثابتة فقط): ملفاته مؤقتة، فتضيع قاعدة البيانات والصور.
- الخيارات المناسبة: خادم VPS صغير، أو منصة مثل Render أو Railway **مع قرص دائم مدفوع**.
- اضبط في الاستضافة: `NODE_ENV=production`، `APP_SECRET` (سر عشوائي)، `DATA_DIR` (مسار القرص الدائم)، `BASE_URL` (رابط الجريدة)، `TRUST_PROXY=1`.

## 5. النسخ الاحتياطي والاستعادة

**أخذ نسخة** (يمكن والتطبيق يعمل):
```
node scripts/backup.js
```
تُنشأ نسخة في `backups\التاريخ_الوقت\` وتشمل **قاعدة البيانات كاملة + كل الصور** + ملف `manifest.json` بعدد المقالات والصور. انسخ هذا المجلد إلى مكان آخر (فلاشة أو Google Drive). يُنصح بنسخة أسبوعية على الأقل، ونسخة قبل كل تحديث.

**الاستعادة:**
1. أوقف التطبيق.
2. ```
   node scripts/restore.js --from backups\2026-11-08_183000 --yes
   ```
3. شغّل التطبيق من جديد.

قبل الاستعادة يحفظ السكربت تلقائيًا نسخة من بياناتك الحالية في `backups\pre-restore-...` احتياطًا.

## 7. معلومات تقنية مختصرة

| | |
|---|---|
| بيئة التشغيل | Node.js 22.13+ (أو 24) — بلا أي اعتماديات خارجية |
| قاعدة البيانات | SQLite المدمجة في Node.js (ملف واحد `data/app.db`) — المخطط في `src/migrations/` |
| الصور | تُضغط في المتصفح، ثم يفحص الخادم نوعها الحقيقي ويحذف بياناتها الوصفية (الموقع الجغرافي…) ويحفظها في `data/uploads` خارج المجلد العام |
| الأمان | كلمات مرور مجزأة (scrypt)، جلسات HttpOnly، حماية CSRF وXSS وحقن SQL، قفل الحساب بعد 5 محاولات خاطئة، تحديد معدل الطلبات، صلاحيات تُفحص في الخادم لكل طلب |
| الخطوط | Amiri (العناوين والمتن) و IBM Plex Sans Arabic (الواجهة) و Reem Kufi (الترويسة) — من Google Fonts |

**معالجة الصور الاختيارية:** إن أردت إعادة ترميز كاملة للصور على الخادم (أعلى أمانًا وضغطًا)، نفّذ مرة واحدة: `npm install sharp` — يكتشفها التطبيق تلقائيًا. دونها يعمل التطبيق بالكامل بمعالجة مدمجة.

**الخطوط بلا إنترنت خارجي:** إن أردت عدم تحميل الخطوط من Google، نزّل ملفات الخطوط الثلاثة (رخصة OFL مجانية) وضعها في `public/fonts/`، وأضف تعريفات `@font-face` في أول `public/css/app.css`، واضبط `FONTS_CDN=0`.

## 8. هيكل المجلد
```
AlSahafiAlSaghir/
├─ تشغيل الجريدة.bat      تشغيل بنقرة مزدوجة على ويندوز
├─ server.js              نقطة التشغيل
├─ src/                   كود الخادم (المسارات، الأمان، القوالب، قاعدة البيانات)
│  ├─ migrations/         مخطط قاعدة البيانات وملفات الترحيل
│  ├─ routes/             الجريدة، المكتب، غرفة التحرير، الصور، الدخول
│  └─ views/              صفحات HTML
├─ public/                CSS وJavaScript وأيقونة الموقع
├─ scripts/               إنشاء مسؤول، نسخ احتياطي، استعادة
├─ tests/                 الاختبارات الآلية
├─ deploy/                ملفات إعداد خادم VPS (systemd و Caddy)
├─ docs/                  دليل النشر ومخطط البيانات
├─ Dockerfile             للنشر على منصات الحاويات
├─ .env.example           نموذج الإعدادات
└─ data/                  (يُنشأ تلقائيًا) قاعدة البيانات والصور — لا تحذفه
```
